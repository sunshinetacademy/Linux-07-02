1 افتتاحية: مشكلة المدرسة 😅

تخيلوا مدرسة فيها ممر واحد لكل حاجة:

  • 🚪 أي حد يدخل أي فصل — حتى الفصول اللي مش بتاعته!
  • 🗄️ أي طالب يقدر يفتح درجات الزمالك ويغيرها!
  • 💰 غرفة الأوقاف مفتوحة للكل!

كارثة، صح؟ 😱
ده بالظبط اللي هيحصل لو كل مستخدمين الكمبيوتر عندهم صلاحيات كاملة! وعشان كده أي نظام حقيقي (Windows وLinux والموبايل بتاعك) فيه مستخدمين وصلاحيات — ودي أول وأهم حاجة بتقفل بيها الثغرات.

💡
ربط بمجال الأمن السيبراني: المبدأ اللي بنشتغل بيه اسمه Least Privilege (أقل صلاحية ممكنة) — كل حد ياخد بس الصلاحيات اللي يحتاجها لشغله، ولا حاجة زيادة. المبدأ ده بيستخدمه كل محلل أمني ومهندس شبكات في العالم.

2 مين اللي جوه النظام؟ — عالم المستخدمين

👤

المستخدم العادي

زي طالب في المدرسة 🎒 — يقدر يلعب في "المكتبة بتاعته" (الـ Home folder)، ينشئ ملفاته، بس مش يقدر يغير حاجة في النظام كله ولا في ملفات زمايله.

👑

root — الملك

زي مدير المدرسة 🏢 — يقدر يعمل أي حاجة: يغير أي ملف، يمسح أي حاجة، يركب برامج، يغير كلمات السر. اسمه في Linux هو root ورمزه في Terminal هو #.

🔑

sudo — مفتاح الملك المؤقت

معناها Super User DO = "نفّذ الأمر ده بصلاحيات الملك لثواني". زي ما تقول للمدير: "محتاج مفاتيح غرفة السيرفر 5 دقايق بس" — والمدير بيبص فيك الأول! 👀

الفرق اللي هتشوفه بعينك
kali@sunshine:~$ ← $ يعني مستخدم عادي (كالي)
root@sunshine:~# ← # يعني الملك نفسه (root) — خطر وقوة!
🚨
قصة حقيقية من قواعد الأمان: لو شغلت Terminal بصلاحيات root وخطيت في أمر واحد زي rm -rf / — هتمسح النظام كله ولا رجع فيه حاجة!
علشان كده المحترفين بيقعدوا مستخدمين عاديين 99% من الوقت، وبيستخدموا sudo بس لما يحتاجوه فعلًا. القوة الكبيرة = مسؤولية كبيرة 🕷️
kali@sunshine — جرب بنفسك
kali@sunshine:~$ whoami
kali
kali@sunshine:~$ sudo whoami
[sudo] password for kali:
root
# نفسك! بس بصلاحيات الملك 👑

3 فك شفرة الصلاحيات — rwx 🕵️

كل ملف في Linux ليه 3 سلاسل صلاحيات — تشبه الأقسام في مدرسة:

👤 صاحب الملف
(Owner)
r w x
👥 المجموعة
(Group)
r - x
🌍 الباقين كلهم
(Others)
r - -
r = read (قراءة 📖)
w = write (كتابة ✏️)
x = execute (تنفيذ ▶️)
- = ممنوع 🚫

مثال حي: rwxr-x--- معناه:

الجهةالصلاحيةبالعربي
الصاحبrwxيقرأ ويكتب ويشغل — كل حاجة ✅
المجموعةr-xيقرأ ويشغل بس — مش يقدر يعدل ⚠️
الباقين---لا حاجة خالص — الملف مستخبي عنهم 🚫

🔎 نقراها بعيننا — ls -l

kali@sunshine
kali@sunshine:~$ ls -l secret.txt
-rw-r--r-- 1 kali kali 24 Oct 8 11:30 secret.txt
# └──┬──┘ └─┬─┘ └─┬─┘
# الصلاحيات الصاحب المجموعة
# أول حرف: - يعني ملف، d يعني مجلد (directory)

🧮 الصلاحيات بالأرقام — السر العجيب (Octal)

كل حرف ليه رقم سري:

الحرفرقمهليه؟
r قراءة42²
w كتابة22¹
x تنفيذ12⁰

وبنجمع! أمثلة تفهم بيها كل حاجة:

الرمزالحسابالرقممعناه
rwx4+2+17كل الصلاحيات 👑
r-x4+0+15قراءة وتنفيذ بس
rw-4+2+06قراءة وكتابة
r--4+0+04قراءة فقط 📖
---0+0+00ممنوع تمامًا 🚫

فبكده chmod 700 يعني: 7 للصاحب (كل حاجة) — 0 للمجموعة (ولا حاجة) — 0 للباقين (ولا حاجة) = ملف سري تمامًا! 🤫

kali@sunshine — chmod بالمثال
kali@sunshine:~$ echo "my diary" > diary.txt
kali@sunshine:~$ chmod 600 diary.txt
# 6 = rw للصاحب | 0 = ممنوع للمجموعة | 0 = ممنوع للباقين
kali@sunshine:~$ ls -l diary.txt
-rw------- 1 kali kali 9 Oct 8 11:35 diary.txt
# قفلنا الملف! 🔒
kali@sunshine:~$ chmod +x script.sh
# طريقة تانية: +x = "زود صلاحية التنفيذ" على اللي كان موجود

4 🎮 لعبة اليوم: "اختراق الملف السري" (Mini CTF)

🏴 السيناريو

المدرّس خبّأ 3 ملفات سرية في المجلد المشترك /home/shared/، كل ملف فيه جزء من الرمز السري لعلامة 🏆:

1

ملف 1 — محمي غلط!

صلاحياته مفتوحة للكل... بس متخفي! استخدم ls -la عشان تلاقيه (المخفي يبدأ بنقطة .)

2

ملف 2 — مقفول بالصلاحيات

لو حاولت تقرأه هتظهرلك رسالة Permission denied ❌ — الحل: sudo cat! 🗝️

3

ملف 3 — ملف سكريبت مخفي

صلاحيته 600 ومفيهوش x — لازم تفكر: أقرأه بـ cat وألاقي جواه الأمر اللي بيديني الرمز الأخير!

🏆 الفريق الأول يجمع الرمز الكامل = فائز اليوم!

🎯
الدرس الأمني من اللعبة: انتبهتوا إزاي الصلاحيات الغلط (ملف 1) بتحول السر لأكلة؟ ده اسمه في المجال File Permission Misconfiguration — وده من أشهر الثغرات اللي بيلقاها الاختصاصيين في اختبارات الاختراق الحقيقية! انتوا عملتوا أول ثغرة اكتشاف في حياتكم 🥇

5 🧠 اختبر نفسك — كويز تفاعلي (اضغط على الإجابة!)

❓ سؤال 1: في Terminal، رمز # آخر السطر معناه إيه؟
❓ سؤال 2: صلاحية r-- تعادل قوام رقم كام؟
❓ سؤال 3: عايز تقرأ ملف صاحبه مش انت — إيه الحل المحترف؟
❓ سؤال 4: chmod 777 على ملف سري — قرار آمن؟

📌 خلاصة المحاضرة + الواجب

👤 المستخدم العادي — محدود بصلاحياته، وده حماية مش قيد
👑 root — قوة مطلقة وخطر مطلق، ما بنقعدوش فيه
🔑 sudo — مفتاح مؤقت بصلاحيات root عند الحاجة فقط
🔓 rwx — قراءة/كتابة/تنفيذ لـ 3 فئات: صاحب، مجموعة، باقيين
🧮 الأرقام — r=4, w=2, x=1 وجمع: 777 و600 و644 و700
🛡️ Least Privilege — أقل صلاحية ممكنة = أمان أعلى

📝 الواجب المنزلي

  1. أنشئ 3 ملفات وأعطيهم الصلاحيات دي: 700 و644 و755 — وصور شاشة ls -l للنتيجة
  2. اكتب في ملف: "يعني إيه 755 بالعربي؟" (لمين كل رقم؟ وليه مناسب للسكريبتات؟)
  3. ❓ سؤال التفكير (تحدي): المجلدات لازم يكون فيها صلاحية x عشان تدخلها — ليه رأيك؟ بحث Google مقبول ومشجع! 🔍
  4. 🎁 اختياري ممتع: اسأل حد كبير في عائلتك عن كلمة السر بتاعته — هو مكتوبة على ورقة ملزوقة على الشاشة؟ 😄 صمم له "نصيحة أمنية" منك كخبير مبتدئ!
